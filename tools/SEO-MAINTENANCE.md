# Search metadata and article discovery

The site still uses GitHub Pages and its existing browser CMS. No build system or hosting settings were changed.

After adding or removing posts, refresh the sitemap and initial blog listing:

```sh
python3 tools/generate-discovery.py
node --test tests/seo.test.cjs
python3 tools/check-seo.py
```

Commit the generated `sitemap.xml` and `blog.html` with the content update. Browser CMS updates immediately affect the JavaScript-rendered blog, but the static fallback listing and sitemap require this refresh. The CMS now preserves a post's original `id` when editing its title and retains optional `aliases` fields. Add confirmed previous IDs to that post's `aliases` array to repair historical links.

The five main pages have canonical and social metadata directly in their HTML. Article metadata is generated by `article-seo.js` after the existing post data loads. Article content still requires JavaScript; prerendering all articles is a separate future improvement, particularly for crawlers that do not run JavaScript and social preview bots.

After deployment, verify `/robots.txt`, `/sitemap.xml`, the four legacy page redirects, and both old article IDs. Then submit `https://alicekimlicsw.com/sitemap.xml` in Search Console and inspect the key pages. The legacy page files use immediate HTML refresh redirects compatible with static hosting, not server-side HTTP 301 responses. The old `/untitled` URL remains unmapped because its intended replacement is unknown.

Private analytics and the review report are stored outside this public site's repository.
