# Internal notes — not published

GitHub Pages builds this site with Jekyll, which skips any directory whose name
starts with an underscore. Anything in `_notes/` therefore stays in the
repository and out of the published site.

These files used to sit at the repository root and under `tools/`, where Pages
served them at `alicekimlicsw.com/OPEN-QUESTIONS.md` and
`alicekimlicsw.com/tools/SEO-MAINTENANCE.md` — publicly readable. Keep internal
working documents here.

- `OPEN-QUESTIONS.md` — the running record of client review rounds, decisions
  made and questions still open.
- `SEO-MAINTENANCE.md` — release notes and the reasoning behind each change, for
  whoever picks the site up next.
